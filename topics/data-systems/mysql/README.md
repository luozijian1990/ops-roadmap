# MySQL 学习指南

本主题是 MySQL 运维与使用入口，聚焦安装配置、SQL、存储引擎、备份恢复、复制和性能诊断，适合数据库值班与应用工程师查阅。

## 可以学到什么

- 部署 MySQL 并管理用户、权限、配置和生命周期。
- 理解 InnoDB、事务、索引和 SQL 执行基础。
- 使用监控、慢查询和锁信息定位性能问题。
- 设计备份恢复、复制与高可用操作流程。

## 阅读建议

- 先在独立实例练习 SQL 和备份恢复，再接触生产变更。
- 涉及数据删除、复制切换时，先确认备份可恢复并保留审计记录。
