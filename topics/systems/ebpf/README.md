# eBPF 运维与故障排查学习指南

本主题介绍 eBPF 工具链、程序生命周期、验证器和观测案例，面向需要低侵入监控、性能诊断、网络和安全观测的 SRE。

## 可以学到什么

- 判断 eBPF 适合解决的监控和排障问题。
- 使用 bpftrace、BCC、libbpf 跑通系统调用观测。
- 理解程序、挂载点、Map、字节码和验证器的关系。
- 诊断加载失败、数据缺失和内核兼容性问题。
- 设计低开销、可审计的生产观测工具。

## 阅读建议

- 先在测试内核确认 BTF、权限和工具版本，再部署到生产节点。
- 观测程序需设置采样、生命周期和资源上限，避免排障工具制造新负载。
