# 容器核心技术学习指南

本主题从容器运行机制进入 Namespace、Cgroups、镜像和运行时，帮助运维工程师理解容器隔离与资源问题的内核基础。

## 可以学到什么

- 构建并运行最小容器，理解镜像、进程和生命周期。
- 观察 Namespace 如何隔离进程、网络和挂载。
- 使用 Cgroups 理解 CPU、内存等资源限制。
- 将容器现象映射到宿主机内核和运行时行为。
- 为容器故障排查建立可复现的实验方法。

- 在 Linux 主机或虚拟机实验，配合宿主机与容器视角对照观察。
- 先理解隔离和资源控制，再进入 Docker/Kubernetes 上层实践。
