# Agent 扩展工程学习指南

本主题面向运维工程师与 SRE，集中整理 Agent Skills 与 MCP 学习笔记。内容从可复用的任务方法、资源组织和执行接口出发，逐步学习如何扩展 Agent 的工作能力，以及如何验证实际效果。

## 可以学到什么

- 理解技能包结构、渐进加载、元信息和最小运行过程。
- 将真实运维经验组织成有输入、步骤、证据和输出约定的技能。
- 分别评估触发准确性和输出质量，建立基线、断言与人工反馈流程。
- 设计可自动调用的脚本，处理路径、依赖、错误、结构化输出与重试。
- 理解自建 Agent 中的发现、解析、激活、资源访问和上下文维护。
- 理解 MCP 的 Host、Client、Server、数据层和传输层边界。
- 以 personal-mcp 的 Prometheus 查询插件为例，理解即时与区间查询、工具契约、结果语义和 Client 调用循环。
- 评估远程接入、渐进式工具发现、Code Mode、沙箱和 MCP 安全风险。

## 阅读建议

Skills 笔记共 7 章、38 个学习小节，包含 11 张 Mermaid 流程图。先完成掷骰子最小案例，再围绕本地巡检报告案例学习编写、评估和脚本接口，最后阅读宿主集成章节。

MCP 笔记共 9 章、35 个学习小节，包含 8 张 Mermaid 图。先建立协议和连接架构，再通过文内 Prometheus 查询案例理解 Server 与 Client 原理，最后学习大规模 Host 优化、安全边界和运维判断。长任务小节区分进度通知、MRTR 与 Tasks 扩展。

巡检案例中的数据与阈值是教学设定。确定性统计脚本已进行本地测试；客户端交互和真实模型对照评估在笔记中作为读者练习说明。

## 后续内容组织
