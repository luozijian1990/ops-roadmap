# DeepAgent 学习指南

本主题介绍基于 LangChain 生态的 Deep Agents，重点是规划、文件系统、子 Agent 和长任务执行。适合将研究、排障和多步骤运维任务组织成可恢复流程。

## 可以学到什么

- 理解 Deep Agents 的组成、适用边界和运行机制。
- 创建 Agent，配置系统提示词、搜索工具与流式处理。
- 使用规划、上下文管理和文件系统能力处理长任务。
- 设计工具权限、状态持久化和人审节点。

## 阅读建议

- 先跑通最小 Agent，再逐项加入搜索、子 Agent 和持久化能力。
- 生产接入前为每个工具定义超时、权限和失败恢复策略。
