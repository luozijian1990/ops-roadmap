# Claude Agent SDK 学习指南

本主题面向希望把 Claude 能力接入工具和运维工作流的工程师，聚焦 SDK 的概念、会话、工具调用与文件系统能力。它适合用于构建可审计的运维助手和自动化原型。

## 可以学到什么

- 理解 Agent SDK、Claude Code 与模型/工具之间的边界。
- 编写快速入门程序，管理会话、提示词、流式输出和错误。
- 将文件读写、命令执行等能力接入 Agent，并评估权限风险。
- 设计面向 SRE 的人机协作、审计与回滚边界。

## 阅读建议

- 先完成快速入门，再阅读工具权限和生产集成部分。
- 示例涉及命令执行时，使用隔离环境并保留操作日志。
