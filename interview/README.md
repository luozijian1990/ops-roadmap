# 面试与简历学习指南

这里整理了从写简历、准备面试，到现场回答和事后复盘的一套方法。你可以先弄清面试官想了解什么，再整理自己的经历，练习怎样把做过的事情和真实想法讲明白，最后从每次面试中找出下一步要改进的地方。

重点不是背答案或套话术，而是知道该准备什么、为什么这样准备，以及怎样用自己的真实经历回答问题。

## 可以从中学到什么

- **看懂面试**：知道简历筛选、技术面和主管面分别想了解什么，不再把面试简单理解成答题。
- **准备材料**：从岗位描述中找出重点，把零散经历整理成随时可以拿出来讲的案例。
- **写好简历**：少写空泛的自我评价，多写自己做过什么、遇到什么问题、采取了什么行动。
- **把话讲清楚**：组织好自我介绍、技术解释和项目经历，让对方容易抓住重点。
- **面对追问**：看懂面试官为什么继续往下问，也知道遇到不会的问题时应该怎样展开思考。
- **说明自己的能力**：用真实经历讲清楚自己怎样学习、改进、合作、推动事情和解决问题。
- **看懂面试官**：了解面试官怎样准备问题、观察回答、记录反馈，并把几轮面试的信息放在一起考虑。
- **做好复盘**：分清自己是知识没掌握、经历准备不足，还是现场没有表达清楚，再决定下一步练什么。

## 这里不会讲什么

- 不整理需要背诵的技术题答案，也不用固定话术代替真实理解。
- 不提供简历版式、校招时间表、网申流程、谈薪方法或 Offer 选择建议。
- 关于面试官的内容只用来帮助你理解面试，不会写成一套面试官培训教程。
- 全部内容会重新整理和讲解，不会照着某一门课程的章节复述。

## 怎样使用这套内容

### 第一次学习时

先跟着第一册把自己的经历完整整理一遍，再用第二册练习怎样说。不要只看例子，要换成自己真正做过的事情，看看能不能讲清背景、自己的责任、采取的行动、最后的结果和事后的想法。参加过模拟面试或真实面试之后再读第三册，会更容易理解面试官为什么这样追问。

### 准备具体岗位时

1. 阅读岗位描述，标出主要工作、必要能力，以及自己还不确定的地方。
2. 从个人经历中找出与这些要求有关的事情，没有做过的部分如实说明。
3. 调整简历的信息顺序，让最重要的内容更容易被看到。
4. 顺着简历想一想对方可能继续问什么，并真正说出声练习几遍。
5. 面试结束后记下遇到的问题、自己的回答和卡住的地方，再决定下一轮重点准备什么。

### 复盘时

不要只用“答对了多少题”判断一次面试。还要回想自己有没有听懂问题、有没有给出具体事实、有没有讲清个人责任、思考过程是否容易理解，以及这个岗位是否真的适合自己。没有通过，可能是能力还不够，也可能是方向并不匹配，或者只是现场没有把关键经历讲清楚。
