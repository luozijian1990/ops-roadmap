# 可靠性与 SRE 案例

本分类收录以业务连续性、故障预防和恢复能力为核心结果的案例，包括 SRE 转型、SLA/SLO、高可用、容灾、多活、应急响应、风险治理和故障演练。

## 分类边界

- 观测平台自身的采集、存储和查询建设归入 `observability/`。
- 算法或模型主导的异常检测、RCA 和自愈归入 `aiops/`。
- Kubernetes 或多云平台自身的运维治理归入 `cloud-native/`。
- 成本和资源利用率是首要目标时归入 `finops/`。
