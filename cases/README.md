# 企业案例库

本目录收录公开技术分享、文章和演讲中可复用的运维、SRE 与平台工程案例。案例库保存经过结构化整理的单个实践，`topics/` 则负责把多个案例与基础知识进一步综合成系统化学习笔记。

## 目录职责

- `temp/`：待处理的原始整理稿，可能包含 ASR 错误、重复内容、推广信息或未经核验的数据。
- `cases/`：已完成命名、归类和结构化整理的案例。收录只表示已归档，不表示事实已经核验。
- `topics/`：跨案例提炼后的知识体系和学习路线，是 Roadmap HTML 的内容源。

原始材料不得因为导入案例库而删除。案例正文中的重要数字、效果描述和架构结论，应回到公开来源进行核验。

## 固定分类

| 主分类 | 收录范围 |
| --- | --- |
| [`reliability/`](./reliability/) | SRE、SLA/SLO、高可用、容灾、多活、故障管理、应急响应和演练 |
| [`observability/`](./observability/) | 指标、日志、Trace、告警、监控平台和可观测数据平台 |
| [`devops/`](./devops/) | CI/CD、研发运营一体化、交付平台、自动化运维和 DevSecOps |
| [`aiops/`](./aiops/) | 异常检测、根因分析、智能告警、自愈、运维大模型和 Agent |
| [`cloud-native/`](./cloud-native/) | Kubernetes 运维、多云、混合云、云原生平台和架构转型 |
| [`finops/`](./finops/) | 云成本、资源效能、容量治理和 FinOps 组织机制 |
| [`engineering-management/`](./engineering-management/) | 技术管理、团队建设、工程效能和项目管理 |

公司、行业和技术产品不是主分类。它们应写入标签或正文，避免同一案例被复制到多个目录。

## 主分类判定

新增案例时依次回答以下问题：

1. 案例最终要改善的核心结果是什么？
2. 方案的主要建设对象是什么？
3. 标题去掉公司名和产品名后，最准确的问题域是什么？

当案例同时涉及多个领域时，按主要建设对象确定唯一主分类：

- 重点是故障预防、恢复和业务连续性，归入 `reliability/`。
- 重点是遥测采集、存储、查询、告警或观测平台，归入 `observability/`。
- 重点是研发流程、发布流水线和交付平台，归入 `devops/`。
- 重点是算法、模型或 Agent 对运维数据的分析和决策，归入 `aiops/`。
- 重点是 Kubernetes、多云或云平台本身的运行治理，归入 `cloud-native/`。
- 重点是成本分摊、资源利用率或容量运营，归入 `finops/`。
- 重点是人员、组织、管理和协作机制，归入 `engineering-management/`。

无法归类时，先在最接近的分类 README 中记录边界问题。只有现有分类无法表达、预计至少能收录 3 篇案例，并且边界能够清楚描述时，才新增一级分类。

## 文件规范

- 路径使用 `cases/<category>/<case-slug>.md`。
- `<case-slug>` 必须使用小写 kebab-case，优先采用“组织或场景 + 核心实践”。
- 每篇案例必须且只能有一个 H1，第一行必须是 `# <案例标题>`。
- 正文应尽量使用 H2 表示阶段，H3 表示具体实践，H4 表示内部知识点。
- 不复制同一案例。次要领域通过标签和“关联主题”表达。
- Mermaid、表格、代码和有意义的 Markdown 换行应保留。

新案例以 [`case-template.md`](./case-template.md) 为结构基准。导入完成后，必须把链接加入对应分类的 `README.md`。

## 标准流程

```text
新材料
  -> 检查公开来源与内容完整性
  -> 确定唯一主分类
  -> 使用模板建立案例文档
  -> 清理 ASR 错误和推广内容
  -> 更新分类 README 索引
  -> 关联已有 topics 学习笔记
  -> 核验重要数字、效果描述和架构结论
```

完成新增或调整后运行：

```bash
./scripts/validate-cases.sh
```

## 与学习路线的关系

案例文件回答“某个组织在特定约束下怎样解决问题”。`topics/` 中的学习笔记回答“这一类问题有哪些通用方法、如何选择以及如何实施”。当同一主题积累了多个已复核案例后，应在 `topics/` 中建立综合笔记，并从案例的“关联主题”链接过去。
