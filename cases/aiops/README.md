# AIOps 与运维智能化案例

本分类收录异常检测、智能告警、根因分析、容量预测、故障自愈、运维大模型和 Agent 实践。

## 分类边界

- 没有算法或智能决策主体的普通监控平台归入 `observability/`。
- 没有模型参与的故障流程和自动化 Runbook 通常归入 `reliability/` 或 `devops/`。
- 案例必须区分规则、统计学习、机器学习、LLM 和 Agent，不能统一包装成 AIOps。
