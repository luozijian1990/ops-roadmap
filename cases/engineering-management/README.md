# 技术与工程管理案例

本分类收录技术管理转型、团队建设、工程效能、项目管理和架构师能力发展案例。

## 分类边界

- 具体平台、工具或技术体系的建设按其主要问题域归类。
- 只有当组织、人员、协作和管理方法是正文主体时才归入本分类。
- 泛职业建议应有明确实践背景，否则不进入案例库。
