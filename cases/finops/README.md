# FinOps 与容量治理案例

本分类收录云成本管理、成本分摊、资源效能、容量运营、弹性伸缩和 FinOps 协作机制案例。

## 分类边界

- 单纯介绍 Kubernetes 调度和集群治理的内容归入 `cloud-native/`。
- 容量预测若主要讨论算法能力，可归入 `aiops/`；若主要讨论成本和资源决策，归入本分类。
- 降本是附带效果、核心目标是稳定性时归入 `reliability/`。
