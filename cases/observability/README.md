# 可观测性案例

本分类收录指标、日志、Trace、告警、监控系统和统一可观测数据平台的建设与演进案例。

## 分类边界

- 主要目标是故障组织、应急流程或业务连续性时归入 `reliability/`。
- 主要创新来自机器学习、根因算法或 Agent 决策时归入 `aiops/`。
- 仅以 Prometheus、OpenTelemetry 等产品为背景并不自动归入本分类，必须以观测能力建设为主体。
