# 实验验收记录

## 环境与目标

### 实验条件

- 路线 / 阶段 / 节点 ID：
- 日期、系统版本、软件版本、代码提交：
- 实验拓扑与资源上限：
- 要验证的行为与成功标准：
- 中止条件、恢复入口：

## 实验过程

### 正常基线

记录命令、实际输出、业务记录数、版本与请求耗时。

### 故障与诊断

记录故障注入命令、开始时间、观察结果、候选原因和用于排除原因的证据。区分真实故障与应用模拟。

### 恢复与反证

记录恢复命令、结束时间和相同请求的结果。检查数据遗漏或重复、残留故障开关和实验资源。

## 结论与交接

### 验收结果

- 已验证：
- 未通过或未覆盖：
- 检测与恢复耗时、实际数据损失：
- 他人复现入口：
- 下一项改进及验收方式：

不要把密码、密钥或真实用户数据放入记录。文件路径可以粘贴到路线节点的“验收笔记”。
